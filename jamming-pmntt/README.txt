JAMMING PMNTT UNUD 2026 - prototipe tampilan

Buka index.html di browser. Struktur:
- index.html  : isi halaman
- style.css   : tampilan
- script.js   : voucher, formulir, dan hitung mundur
- assets/     : foto latar dan logo

Pengaturan harga dan kuota ada di bagian CFG pada script.js.
Pembayaran BNI VA, e-ticket, email/WhatsApp, dan dashboard admin belum aktif (butuh server dan payment gateway).
